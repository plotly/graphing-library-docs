--- name: Double Click Delay language: plotly_js suite: configuration order: 11 sitemap: false arrangement: horizontal markdown_content: | `doubleClickDelay` sets the longest interval between two consecutive clicks that counts as a double-click, in milliseconds. The interval runs from the first mousedown to the second mouseup. The default is 500 ms. This setting propagates to all on-subplot double clicks, except on geo and map subplots. --- var data = [{ type: "bar", y: [3, 5, 3, 2], x: ["2019-09-02", "2019-10-10", "2019-11-12", "2019-12-22"] }]; var layout = {xaxis: {type: 'date'}}; var config = {doubleClickDelay: 1000} Plotly.newPlot("myDiv", data, layout, config)
