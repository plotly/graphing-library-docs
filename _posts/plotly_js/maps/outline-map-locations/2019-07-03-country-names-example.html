--- name: "locationmode: 'country names'" language: plotly_js suite: outline-map-locations order: 3 sitemap: false arrangement: horizontal markdown_content: | Set `locationmode: 'country names'` to use full country names in `locations`. Names are resolved by [country-iso-search](https://github.com/plotly/country-iso-search), which matches a country's name, its ISO-2 and UN M49 codes, and a curated set of aliases — historical and native names, and common alternates. Matching ignores case, accents, and punctuation, so `'Cote d'Ivoire'`, `'Türkiye'`, and `'St. Kitts and Nevis'` all resolve. See the library's [country list](https://github.com/plotly/country-iso-search/blob/main/src/countries.ts) for every accepted name and alias.
